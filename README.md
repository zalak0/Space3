# Space3
Satellite code simulation and STM32 implementation of that code

## Structure

- **Simulation** folder includes code that simulates given code that is NOT in STM32.
- **STM32 Implementation** folder includes code that will be used for the STM32/in the satellite
> Organise each sub-folder into subsystem based folders rather than simulation-specific folders for modularity.
